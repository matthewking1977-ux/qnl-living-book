# QNL homepage — Concept F "The Living Book" (MVP)

Tender concept. Live: https://qnl-living-book.vercel.app/

Vite + React 19 + TypeScript, Tailwind CSS 4, GSAP ScrollTrigger + Lenis, CSS 3D only.

```bash
npm install
npm run dev
```

- `npm run assets` rebuilds `public/img` from `/assets` (WebP/AVIF, responsive sizes).
- `?debug=1` shows scroll progress `s`, the active phase and FPS.
- `?lang=ar` previews the mirrored right-to-left book (Arabic copy not yet supplied).
- Spread content: `src/data/spreads.ts`. Scroll choreography: `src/components/Book/choreography.ts`.

Status: all six phases built. Lighthouse (mobile, local production build): Performance 100, Accessibility 100.

- `?intro=1` forces the intro for visitors who have already seen or skipped it.

Pop-up artwork: `public/popups/spreadX-layerN.svg`, generated by `scripts/build-popups.mjs`. Replace a file to swap the artwork; position and size live in `src/data/spreads.ts`.
